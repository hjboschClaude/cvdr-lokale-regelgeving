# cvdr-lokale-regelgeving-opzoeken

Agent skill for looking up Dutch municipal regulations on [lokaleregelgeving.overheid.nl](https://lokaleregelgeving.overheid.nl/) (CVDR).

Default scope: gemeente Rotterdam. Source of truth is the live CVDR page; never invent versions or treat vervallen texts as geldend.

Install: copy `cvdr-lokale-regelgeving-opzoeken/SKILL.md` into your agent skills/workflows folder (or sync from this repo).
